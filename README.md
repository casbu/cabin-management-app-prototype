# Coseca App
Interactive application prototype designed in Justinmind to help service workers manage cabin reservations and maintenance requests.

## Features
End User Portal
- Profile Management
- Show available cabins based on calendar picker
- Settings with Log Out feature

Employee Portal
- Service Menu
- View available cabins, rentals, cancellations, and maintenance screens
- Pin cabins being worked on or out of service
- View maintenance visits and orders 

### Tools
Justinmind - Prototyping & Wireframing
